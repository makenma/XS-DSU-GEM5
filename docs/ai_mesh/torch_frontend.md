# Torch frontend

Gate 5 acceptance is owned by [the main decision](torch_gate5_acceptance.json), with the [evidence index](torch_gate5_acceptance.md). The next coding task is the [Gate 6 implementation prompt](torch_gate6_implementation_prompt.md).

The frontend API is [`mesh_ir.frontend`](../../util/mesh_ir/mesh_ir/frontend.py). It accepts a module factory through `export_graph` or an existing `.pt2` through `load_graph`, and returns canonical symbolic Graph IR plus concrete profile variants.

Authoritative inputs are indexed here:

- architecture schema: [`mesh_arch_v1.schema.json`](../../util/mesh_ir/mesh_ir/schemas/mesh_arch_v1.schema.json)
- compile schema: [`mesh_compile_v1.schema.json`](../../util/mesh_ir/mesh_ir/schemas/mesh_compile_v1.schema.json)
- Graph schema: [`mesh_graph_v1.schema.json`](../../util/mesh_ir/mesh_ir/schemas/mesh_graph_v1.schema.json)
- diagnostics: [`diagnostics.yaml`](../../util/mesh_ir/mesh_ir/diagnostics.yaml)
- canonical op registry: [`canonicalize.py`](../../util/mesh_ir/mesh_ir/passes/canonicalize.py)
- examples: [`tiny_mlp.py`](../../util/mesh_ir/examples/tiny_mlp.py) and [`tiny_transformer.py`](../../util/mesh_ir/examples/tiny_transformer.py)

Torch is confined to [`torch_compat.py`](../../util/mesh_ir/mesh_ir/torch_compat.py); Graph IR and backend modules consume the framework-free DTO and do not import Torch.
