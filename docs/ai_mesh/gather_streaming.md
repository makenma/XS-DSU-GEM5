# Indexed HBM gather

The compiler's indexed transfer contract is owned by [GatherGeometry](../../util/mesh_ir/mesh_ir/analysis/gather.py). It separates the admitted table domain, index traversal, destination rows, useful transfer bytes and physical storage extent. Placement and tensor-parallel coverage are exercised by the [streaming integration tests](../../util/mesh_ir/tests/integration/test_gate2_gather_streaming.py).

The [ABI schema](../../util/mesh_ir/mesh_ir/abi/mesh_ir_abi.yaml) owns `GATHER_LOAD`, `GATHER_INDEX_V1` and `EMBEDDING_STAGED_COPY`. The index attribute is projected from admitted geometry. A staged embedding consumer must prove its input state was produced by the gather for the same logical table and indices; its work is an ordered copy. The geometry checks and producer proof are mirrored in [C++ admission](../../src/dev/ai_mesh/mesh_ir_gather.cc). [ComputeCommitter](../../src/dev/ai_mesh/mesh_compute_commit.cc) owns ordered byte copying across physical input and output spans.

Static AXI counts use [indexed row planning](../../util/mesh_ir/mesh_ir/burst_splitter.py) and its [C++ mirror](../../src/dev/ai_mesh/mesh_splitter.cc). The generated `TrafficCountKind` distinguishes geometry-proven exact counts from indexed upper bounds in descriptor and aggregate reports. Useful bytes remain exact; bounds cannot substitute for runtime index evidence.

The [timed index reader](../../src/dev/ai_mesh/gather_index.hh) consumes the layout frozen by C++ admission through actual TensorSram service. [AXI execution](../../src/dev/ai_mesh/axi_tensor_dma_engine.cc) preserves occurrence identity across repeated source addresses; [runtime reconciliation](../../util/mesh_ir/mesh_ir/runtime_gather.py) independently derives requests from declared input indices and checks service timing. [Real AXI tests](../../util/mesh_ir/tests/integration/test_gather_runtime.py) cover changed inputs, duplicate rows, first and later invalid indices, ordered output bytes, and indexed traffic bounds. [Checkpoint component tests](../../util/mesh_ir/tests/unit/test_abi2_runtime_checkpoint.py) preserve index observations.

The [runtime evidence](../../.tmp/docs/qwen3-8b-smoke/stage-b/runtime-gather-result.json) and [Qwen integration status](../../.tmp/docs/qwen3-8b-smoke/stage-b/stage-b.json) distinguish targeted checks from the full-model serving smoke. [Checkpoint evidence](../../.tmp/docs/qwen3-8b-smoke/stage-b/gather-checkpoint-result.json) requests a checkpoint during index service and saves at the supported drained boundary; restored observations, output and protocol closure match uninterrupted continuation.

[Read-error evidence](../../.tmp/docs/qwen3-8b-smoke/stage-b/gather-read-fault-result.json) covers physical HBM read failures and retained occurrence prefixes. [Fault planning](../../util/mesh_ir/mesh_ir/fault_plan.py) shares the indexed address splitter with runtime reconciliation; duplicate table addresses keep distinct transaction identities. The runtime gather oracle validates issue timing, the failing occurrence, successful issued bytes and absence of later-row work.

[Request-cancel evidence](../../.tmp/docs/qwen3-8b-smoke/stage-b/gather-cancel-result.json) consumes CANCEL while gather is active, drains the frozen physical phase and suppresses publication. Cancellation completes through the driver CQ/ACK path.

[Seeded mock evidence](../../.tmp/docs/qwen3-8b-smoke/stage-b/gather-mock-result.json) loads the complete exported table into mock backing, changes runtime indices and compares direct output bytes. The mock memory interface permits initialization only at tick zero; inspection does not perform a timed DMA transfer.

Placement interval operations share [byte-span algebra](../../util/mesh_ir/mesh_ir/analysis/regions.py), with [set-oracle and strided-panel tests](../../util/mesh_ir/tests/unit/test_byte_span_algebra.py). [Placement selection](../../util/mesh_ir/mesh_ir/passes/placement.py) retains full geometry only for each selected candidate. Full-model diagnostic samples and the isolated interval benchmark are indexed by the stage status.
